# Changelog

Все заметки о выпусках проекта **VPD Lab 01** документируются в этом файле.

## [1.0.0] - 2026-11-04

### Добавлено
- Реализация программы «Hello World» на множестве языков программирования (C, C++, Python, JavaScript, TypeScript, Java, C#, F#, Go, Rust, Bash, Prolog и Assembler).
- Настройка конфигураций сборки и запуска для каждого языка.
- Поддержка корректного вывода кириллицы с использованием `setlocale`.
- Полная документация проекта в файле `README.md` с таблицей версий инструментов и команд сборки.
- Симуляция командной разработки и успешное разрешение конфликта слияния (Merge Conflict) в Git.
